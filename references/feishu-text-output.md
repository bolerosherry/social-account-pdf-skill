# 可复制到飞书的文字

用户选择此格式时，在回复中提供完整方案正文，供用户自行复制到飞书文档。不要将其误解为创建飞书文档、发送消息、上传文件或发布；不要调用PDF渲染程序或默认追加PDF。

## 内容与结构

- 先沿用本案例已选模式，再按 [报告写作规则](report-writing.md) 准备可复制正文。标准账号方案包含四维诊断、主体对应的人设或定位、3–5个有顺序的优化动作、15–30个选题，以及用户已确认的同平台对标账号。素人图文铺量按下述分支交付。两种模式均先在当前聊天确认对标候选与最终名单。
- 文首依次写客户公司/品牌名称、项目方案名，以及“动量领航 / Momentum Pilot Technology · 内部资料”。随后直接给正文，避免将过程解释混入可复制内容。
- 标准账号方案的一级标题仍为“一、账号诊断”“二、定位优化”“三、内容方向参考”“四、选题建议”“五、对标账号参考”。第六模块按内容命名。
- 常规品牌账号及素人图文铺量的“五、对标账号参考”只列同平台品牌自营账号。优先同品类、同客群，逐项简述品牌官方账号或区域号、门店号的归属依据，与聊天中确认的名单一致。达人、素人、探店及第三方带货合作帖可作内容示例，铺量模式放在“三、种草帖示例”。归属不明的候选先补证或换选。个人IP常规方案按原规则筛选与确认。
- 用清晰标题、短段落、加粗标签和简单表格呈现，不使用HTML、复杂布局或整篇代码块。动作表上方的小标题只写“优化动作”四个字，无编号、无后缀，与PDF一致。其他正文二级标题按模块连续编号。表格字段不带序号，选题序号和动作表中的执行先后、优先级保留。
- 表格尽量控制为2-5列，不合并单元格、不做嵌套表格。标准方案的15-30条选题全部列出，可按方向分组。用户要求纯文字时，将表格按行改写为短段，信息完整保留。
- 不承诺粘贴后自动保留PDF的绿色、字号、Logo或分页；这些不影响文字版内容的完整度。

## 素人图文铺量文字版

文首方案名写“素人图文种草方案”。正文与PDF保持相同顺序，依次使用“一、铺量目标与品牌号配合”“二、素人图文方向与选题”“三、种草帖示例”“四、从示例延展的选题”“五、对标账号参考”。

简述铺量目标和品牌号辅助信息。将已确认的至少15个不同内容方向整理成表格或分组短段，逐项给出场景或人群、创作视角和对应的图文拟题。目标篇数明确时列出各方向篇数，未给时可写建议数量。另列本批案例衍生的3–5个原创题，逐题标明“对应示例1”等来源及改写角度。

每个采用的用户原帖截图都编示例号，在交付回复中展示原图或附上原图文件。可复制正文用相同示例号标出插图位置并紧接可借鉴做法，便于在飞书中逐张放回。交付前须已按 [铺量评审流程](intake-and-research.md) 在当前聊天确认方向、拟题及衍生题，完成示例分析与既有对标账号评审。内容仅为可供真实创作的拟题和方向，不编写假体验或代为发布。

## 标准账号方案的截图处理

文字复制不等于图片嵌入。在“2、当前账号阶段”标题下直接给表格，不另设截图标题。第一列前三行共享一张首页图（可复制文本以首行提示、后两行留空表示）；第二、三列按行列出粉丝量、获赞与收藏、简介及对应值。底行左格“现状判断”，其余位置填写结论。其后顺次为3、现有内容类型，4、账号主要问题，5、本次方案核心方向。其他代表内容截图只作分析依据。首页图用一次简短插图提示，例如“【此处插入：已提供的账号主页截图】”，并说明完整/局部范围；未收到截图则写“主页截图暂未获取”，不要暗示已嵌入。

对入选对标账号，已取得的主页原图可在正文之外作为附件提供，在对应账号处标明这张图的插入位置。使用已接受的缺图情况时，仅说明其对分析范围的影响。还在等待资料时，先在聊天中处理缺项，不能以插图提示代替缺失材料提前交付。正文不插入本地绝对路径、内部素材地址或未经核验的截图链接。“三、内容方向参考”仍只呈现文字或表格。

## 交付前核对

发出可复制正文前，须按 [对标研究流程](intake-and-research.md) 核实用户已确认最终名单，所有入选者均已核验，材料已补齐或用户已明确接受具体缺口，且已完成近期表现、内容及推荐理由的分析。替换或新增账号一并核对。评审尚未完成时留在研究阶段。再按模式检查标准方案的模块、编号、15–30条选题及优先级，或铺量方案的不同方向数量、拟题、原图及3–5个衍生原创题。不要把未知数据、未核验热点或用户示例写为当前客户事实。文字版不走PDF的字体、页数、图片数量或Poppler检查。

若用户已在同一案例选过格式，后续改稿沿用；用户要求改为PDF或两种都要时，使用同一份分析内容按对应流程交付。此处不替用户选择新案例的格式。
