# 跨行业分析框架

以下用于常规账号方案。铺量方案见[写作规则](report-writing.md)。

先识别行业、业务模式、受众、内容载体和账号阶段，再调整检查重点；一级结构始终保持定位、内容、表达、转化。内部细查，两种交付形式都只保留会改变内容决策的结论。

账号诊断先展示来源原文昵称和用户提供的主页原图，再结合可见粉丝量、获赞与收藏、简介说明当前阶段。没有数据不得推测；主页不完整时明确标注局部截图，阶段证据不足则写明暂无法判断。简短概括现有内容类型后，用定位、内容、表达、转化四维表格呈现主要问题，最后给出本次方案核心方向。

## 定位

检查行业和业务是否可识别、目标用户是否明确、关注价值是否清楚、差异化是否成立。

先区分账号主体。个人 IP 的人设是观众对真实人物的核心印象，需要回答“我是谁、我帮谁、我分享什么、我怎么表达”：真实身份与经历、服务人群、持续分享的价值、表达立场和语言特征。先形成一条核心印象总句，再展开四问；不能用“安排某人出镜、采用某种拍法”替代这些答案。

饭店、企业、品牌等非个人主体写账号定位，概括品类价值、地域或场景、目标人群、真实可支持的差异标签及想建立的核心印象，不强行套个人身份。Slogan 仅在能概括定位时提出，并标为建议。

定位优化首项正文标题编号为1，根据主体显示“账号人设（IP定位）”或“账号定位”；之后用表格呈现目标用户、匹配账号目标的关注/种草/购买/到店理由和记忆点，三个字段不编号。有优化逻辑时使用“2、优化逻辑”。PDF和飞书文字的动作表上方均只写“优化动作”四个字。表内列出3-5项动作及其执行先后和优先级。出镜与拍摄执行建议归入优化动作或呈现形式。

所有身份、地域、场景和差异标签都须有当前账号资料支持。用户成都江景园林、1000㎡、9席示例只用于理解定位表达结构，不能移植为菇菇哒或其他账号事实。

## 内容

检查内容支柱、选题需求、系列化、更新稳定性，以及高低表现内容的可解释差异。

内容支柱不能只有类目名称。每个支柱回答“解决什么用户需求、承担什么任务、占比多少、用什么栏目与形式”。默认三个内容支柱；确有不同用户需求或业务任务时允许 3-5 个，占比合计 100%。比例是建议的首轮试验分配，不能伪装成平台结论。

让建议可推导：当前偏重什么 → 保留什么优势 → 补充或削减什么 → 调整后的结构与配比。不要为每个行业套用同一套 50/30/20。

内容方向模块保留文字方向、比例、栏目和形式，优先用表格，不放截图。对应选题为15-30条，以标题与方向层级的紧凑表格呈现。

## 表达

检查标题、封面、开头、图文或视频结构、语言和视觉识别度，以及平台适配。

同时给出整体内容风格和具体呈现方式，例如场景演示、人物访谈、经验口播、案例图文、真实工作记录。结合现有素材与出镜能力判断。引用对标画面时，指出已确认入选账号的哪条内容、什么画面或结构值得借鉴，区分直接观察与用户提供的描述。

## 转化

检查信任建立、互动设计、主页承接和内容与商业目标的衔接。

已确认业务目标时，说明“哪类内容吸引谁 → 如何建立信任 → 下一步采取什么动作 → 由什么业务承接”。可区分主要业务与辅助商业化；没有业务信息时标记待确认，不替客户编造产品、收入或成交承诺。

执行闭环只用于解释方案如何验证：确认选题 → 制作发布 → 观察内容表现 → 调整方向。详细拍摄审批、人员分工、投流与销售流程不默认展开。

## 证据标签

- **事实**：可从主页、内容、公开数据或可靠来源直接观察。
- **推断**：根据多个事实得出的合理判断，必须显式标记。
- **待确认**：缺少证据且会影响方案的事项，不替客户作答。

知识、服务、电商、本地商家、消费品牌、生活方式和个人 IP 使用同一框架，只调整各检查项的重要程度。
