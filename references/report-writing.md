# 报告写作规则

以下内容要求适用于PDF与飞书文字两种交付。PDF使用本文件的版面规则；文字版另读 [飞书文字交付规则](feishu-text-output.md)，保留内容完整度，不套用分页、固定字号或图片嵌入要求。

- 结论先行，明确指出问题，保持专业，不评价客户能力。
- 每个核心问题按“问题、依据、影响、建议”表达，并标记高/中/低优先级。
- 标准账号方案的核心问题与优化动作为3–5项，内容支柱通常三个，必要时为3–5个，选题15–30条。素人图文铺量使用下述方向与案例要求。两种模式的对标均按用户在当前聊天中确定的最终名单撰写。
- 每段尽量不超过 80 个汉字，删除重复和没有行动价值的内容。
- 诊断必须能追溯到优化动作、内容支柱或选题。
- 选题只写标题、方向、推荐形式和优先级，不扩展成脚本或大纲。
- 热点融入选题，不单独堆砌热点清单。
- 截图保持干净，不在图片上画框、箭头或批注。

## 标准账号方案的模块内容与内部顺序

PDF和飞书文字的小标题均只写“优化动作”四个字，无编号、无后缀。其他正文二级标题前添加1、2、3……的序号，每个一级模块从1重新编号，跨页不重置。编号按正文标题实际显示顺序连续递增；表格字段和行标题不加序号，也不占用正文标题序号。表格列头、粉丝量/获赞与收藏/简介等字段，以及定位/内容/表达/转化四维分类不额外加序号；独立序号列（如选题序号、执行先后）、既有正文列表保持。此规则针对可见的表格字段和行分类，不针对仅用于实现图文布局的底层 Table 容器。

**一、账号诊断**依次呈现：

1. 账号昵称：使用“1、账号昵称”正文小标题加昵称正文，不做字段表格；昵称保留来源原文，不改成客户公司名称或自行缩写。
2. 当前账号阶段：标题在表格上方。左列仅放一张已确认的账号首页原图，跨三行；右侧逐行给出粉丝量、获赞与收藏、简介及对应值。底行左格为“现状判断”，右侧两格合并填写有依据的结论。局部主页注明范围，无主页则注明未获取；代表内容截图仅作分析证据，不用作首页替代，不在此处铺图。
3. 现有内容类型：简短概括已核验样本。
4. 账号主要问题：按定位、内容、表达、转化说明问题与依据。
5. 本次方案核心方向：用简短结论承接后续优化。

**二、定位优化**依次呈现：

正文标题“1、账号人设（IP定位）”或“1、账号定位”按主体选择。个人 IP 先给出真实核心印象总句，再回答“我是谁、我帮谁、我分享什么、我怎么表达”四问；表达指可持续的立场、语言和表达特征。饭店、企业、品牌等非个人主体用定位句概括品类价值、地域或场景、目标人群、真实可支持的差异标签，以及想建立的核心印象。不能用“让谁出镜、怎么拍”等动作清单代替人设或定位。

随后保留三字段表格，字段名称不带序号：

| 字段 | 内容要求 |
| --- | --- |
| 目标用户 | 明确为谁提供什么价值。 |
| 用户关注、种草、购买或到店理由 | 按已确认的账号目标选择适用表述，不默认所有账号都以关注为终点。 |
| 打造账号记忆点 | 用定位、人设、Slogan 或内容风格说明可重复建立的识别点。 |

正文标题“2、优化逻辑”仅在有内容时显示，用简短文字明确“现状 → 调整 → 目标内容结构”。无论是否有优化逻辑，动作表上方的小标题均为“优化动作”。表内列出3-5项动作，按建议执行顺序排列，保留独立的执行先后序号列和高/中/低优先级。出镜安排、拍摄方式等执行建议放在这里或内容方向的呈现形式中。

用户示例只教表达结构。成都、江景园林、1000㎡、9席等信息未在当前账号资料中得到证实时，不得移植为菇菇哒或其他账号的人设、定位和差异标签。旧版 `persona`、`persona_suggestions`、`persona_purpose` 仅兼容历史输入，新版不渲染这些旧字段或动作列表。

**三、内容方向参考**保留文字方向、目的、建议比例、代表栏目和推荐形式，优先使用表格，不放截图。表格内内容方向名称作为行标题，不加序号。

**四、选题建议**按主题方向组织 15-30 个选题，以紧凑表格呈现标题、方向、推荐形式和优先级。主题组标题按出现顺序添加1、2、3……的序号，组内既有选题序号保持。每组体现相同用户需求或内容任务，不展开脚本或长段大纲；热点融入对应方向。

**五、对标账号参考**只写用户已确认、助手已核实并完成分析的同平台账号，以最终名单编号。按照 [对标研究流程](intake-and-research.md)，先在聊天展示真实候选，待用户决定保留、排除、替换或新增。报告中逐个放主页原图，写明近期表现（时间范围、样本与可见指标）、代表内容观察、为什么推荐、可借鉴什么和哪些做法不宜照搬。结论紧邻对应证据。用户已明确接受的材料缺口只说明对分析的影响。仍在等材料时先保留研究记录，资料及分析处理完成后再交付PDF或文字。

常规品牌账号方案与素人图文铺量的第五模块只收录同平台真实品牌自营账号，优先同品类、同客群。品牌官方账号及可核实归属的官方区域号、门店号均可入选。中途候选清单逐项列出所属品牌及自营证据，成稿保留简短依据。达人、素人、探店和第三方带货合作帖归入内容示例，归属未明的账号先补证或换选。个人IP常规方案沿用原候选与确认流程。

**六、按内容命名**：信息足够时用短链路说明业务承接、制作或复盘，不展开完整项目管理流程；内部小标题按出现顺序从1编号。

## 素人图文铺量的内容与示例

PDF与飞书文字均使用报告名“素人图文种草方案”。五个模块依次为“一、铺量目标与品牌号配合”“二、素人图文方向与选题”“三、种草帖示例”“四、从示例延展的选题”“五、对标账号参考”。

铺量模式以目标平台上的素人图文为主。第一模块简述目标人群、业务目标及已有目标篇数，品牌号仅保留能支持图文创作的事实和承接信息。第二模块按不同需求、场景或问题组织至少15个方向，每个方向给出人群或场景、具体创作视角及相应图文拟题。已有目标篇数就按方向分配。未给篇数时可建议15个方向各拟2题，约30条。

方向和拟题先在聊天中供用户选择保留、换题或补充。收到用户提供的目标平台素人帖后，把每张入选原截图放在对应的示例说明旁，指出可借鉴的标题结构、组图顺序或观察角度，再用本项目的真实素材改写。同批示例合计另出3–5个原创题，逐项注明对应的示例编号和切入点，不计入15个方向。若原图后来才提供，须将追加题发回确认。会改变方向、场景或承诺的实质修改只确认受影响的部分。

PDF和飞书文字均以用户确认的方向、拟题及追加原创题为准。完成素材核对、示例展示、原创题分析和独立的对标账号评审之后才交付。拟题需标明尚待采集的真实体验或照片，禁止将未发生的使用、购买、到店或效果写成个人证言。交付物仅供制作，不直接发布。

## PDF版面表达

每页页眉在“动量领航 / Momentum Pilot Technology”左侧使用 `assets/momentum-mark.png` 的透明绿色标志。标志等比例显示，高约10mm，距左边18mm、距顶部约8mm；中英文文字统一位于标志右侧，间隔2.5mm。保留透明背景，不加底色，不改变右侧“内部资料”、分隔线及正文位置。

各模块仅保留一个15pt绿色标题，正文11pt，不再并列黑色页面大标题与绿色模块标题。仅在PDF首页，模块标题上方分两行显示整份报告名称。第一行为客户品牌名（30pt），第二行为方案名（22pt），两行分别水平居中。模块连续排版，可以跨页，同页也可以容纳多个模块。

标准账号方案的前五个模块标题与顺序严格固定，中文数字后使用顿号，不加空格或斜杠：

1. 一、账号诊断
2. 二、定位优化
3. 三、内容方向参考
4. 四、选题建议
5. 五、对标账号参考

需要第六个模块时，按实际内容命名，例如“六、到店承接”。模块编号与页码分别管理；续页如重复模块标题，仍使用完全相同的文字，不加“续”或其他后缀，以页脚页码区分。

从参考方案借鉴清晰模块、信息对照、流程关系和画面举例，优先用表格呈现四维问题、优化动作、内容配比和选题，用简短的前后对照呈现优化路径。账号原图放在诊断模块，对标图与借鉴点相邻，内容方向模块不放截图。封面信息并入首页；业务路径或制作复盘信息紧接已有内容，不为它单独预留整页。

保持白底绿色与紧凑易读的版面，不强制一模块一页，不为达到5-7页硬凑页数。标题与其后正文保持在一起，避免标题孤立在页尾；表格跨页时保持列关系清楚。使用短句与适量留白，不靠缩小11pt正文挤内容，截图不能缩小到失去参考价值。不照搬多色流程图、厚重边框、竖排侧栏和水印。
