## 贯穿整份方案的关系

账号现状与资源 → 定位和人设 → 内容方向与任务 → 配比与呈现形式 → 分组具体选题 → 对标画面与借鉴点 → 业务承接及复盘。

这条关系是分析的主线，不要求每个节点单独占一页。个人 IP 人设回答“我是谁、我帮谁、我分享什么、我怎么表达”，建立真实核心印象；饭店、企业、品牌等非个人主体写账号定位，概括品类价值、地域或场景、目标人群、真实差异标签与核心印象。出镜和拍摄安排归入优化动作或呈现形式。对业务信息不足的账号，商业路径标记待确认。

## 输出应新增的实质内容

1. **内容定位**：按主体给出个人 IP 的真实核心印象及四问，或非个人主体的账号定位；说明目标人群、关注价值、真实差异点，必要时补充 Slogan 和内容风格。
2. **优化推导**：说清要保留的优势、要改变的内容结构，以及改变后的重点。
3. **常规账号的内容矩阵**：3-5 个方向，每项有任务、建议配比、代表栏目和形式。默认三个，不为凑数制造栏目。
4. **主题选题**：15-30个选题按方向组织为紧凑表格，标题应体现具体人群、场景或观点角度。
5. **视觉对标**：最终名单由用户从真实同平台候选中确定，可增删、替换。每个入选者用主页截图和代表内容说明近期表现、推荐依据与具体借鉴点。被诊断账号的首页图放在诊断模块，内容方向模块只用文字或表格。
6. **简短承接**：如已知业务，用内容吸引、信任建立、行动入口与业务承接解释转化；有执行条件时展示精简发布复盘闭环。

## 适用边界

- 不照搬参考方案中的身份经历、医疗效果、行业比例、历史粉丝数、节日热点或具体广告建议。
- “品牌认可”说明方案被接受，不代表增长、营收或治疗效果已得到验证。
- 用户已确认选题只到标题与方向；不因第三份参考较长就默认扩展为观点段落或脚本。
- 用户已确认跨行业工具、每平台一份与动量领航统一视觉；按实际内容连续紧凑排版，允许模块跨页、同页多模块，不强制一模块一页，也不为达到5-7页硬凑页数。参考图不改变这些选择。
- 示例表格用于参考结构，不作为当前账号的新事实；缺失数据不得推测，局部主页截图须明确标注。
- 成都江景园林、1000㎡、9席等定位示例也只教表达结构，不得移植为菇菇哒或其他账号事实。
- 参考图中的运营流程用于理解内容生产和复盘关系，不自动加入投流、审批和完整代运营服务范围。
