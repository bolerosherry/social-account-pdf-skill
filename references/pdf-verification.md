# PDF 验证

真实项目在渲染最终PDF前核对 `benchmark_review_complete` 为 `true`，入选者均为 `user_confirmed: true`、`verified: true`，并与当前聊天最终确认的名单逐项对应。核验、补材料或分析仍在进行时，先完成 [对标研究流程](intake-and-research.md)。

先核对本案例明确选择的是PDF及相应运营模式。选择素人图文铺量时，另行核对 `seeding_review_complete` 为 `true`，方向、拟题及示例衍生题已在当前聊天获用户确认。示例分析和对标评审均完成后才渲染最终PDF。

渲染后必须运行 `scripts/validate_output.py`，检查文档结构、竖版尺寸、品牌文字、客户名称、对标账号和选题完整性，并通过 Poppler 将每页渲染为 PNG。页数服从实际内容，不以5-7页作为通过条件。

逐页检查版式、图片和品牌信息。下列关于账号诊断、定位、固定模块及15–30条选题的检查适用于标准账号方案。素人图文铺量改用文末的内容检查，两种模式都核对已确认的对标账号。

- 是否存在文字裁切、重叠或意外空白页。
- 中文是否出现方框或乱码。
- 正文在手机宽度下是否仍清晰可读。
- 截图是否清晰、未拉伸且没有批注。
- 页眉、页脚、页码是否一致。
- 各模块是否仅有一个15pt绿色标题，且与11pt正文区分清楚；首页仅额外保留30pt客户品牌名与22pt方案名，不出现重复的黑色页面大标题。
- 前五个模块标题及顺序是否严格为“一、账号诊断”“二、定位优化”“三、内容方向参考”“四、选题建议”“五、对标账号参考”；第六个模块是否按内容命名。
- 除“优化动作”外，正文绿色二级标题是否带1、2、3……连续序号，每个一级模块从1重新编号，跨页不重置。表格字段和行标题是否无序号，且不占正文标题序号。表格列头、粉丝量/获赞与收藏/简介等字段和四维分类不额外编号，正文列表与选题/执行先后等独立序号列保持原规则。
- 续页如重复模块标题，是否保持相同文字，未添加“续”、空格或斜杠等改写，并由页脚页码区分。
- 品牌绿与正文的对比度是否足够。
- 是否连续紧凑排版，允许模块跨页、同页多模块，没有为一模块一页或固定页数留下大块空白。
- 模块标题是否与后续内容在一起，没有孤立在页尾；表格跨页后是否仍能清楚对应各列。
- 诊断依次为1账号昵称、2当前账号阶段、3现有内容类型、4账号主要问题、5本次方案核心方向。阶段标题在表格上方；左侧一张首页图跨三行，右侧对应三项指标，最下行现状判断。未取得首页不使用内容截图代替，不附其他样本图。
- “二、定位优化”首项编号1是否根据主体显示“账号人设（IP定位）”或“账号定位”：个人 IP 是否有真实核心印象总句及“我是谁、我帮谁、我分享什么、我怎么表达”四问；非个人主体是否概括品类价值、地域或场景、目标人群、真实差异标签及想建立的核心印象。
- “二、定位优化”是否保留目标用户、用户目标理由、打造账号记忆点三字段表格，三个字段均不带序号。有优化逻辑时是否显示“2、优化逻辑”。无论有无优化逻辑，动作表上方是否仅有“优化动作”四个字，无编号、无后缀，表内3-5项是否标有独立执行先后序号及优先级。
- 是否把让谁出镜、怎么拍等执行建议放在优化动作或呈现形式中，没有用这些动作代替人设或定位；新版是否不再渲染历史 `persona`、`persona_suggestions`、`persona_purpose` 字段。
- 定位、优化逻辑、内容配比和选题方向是否彼此对应。
- “三、内容方向参考”是否保留文字方向、比例和形式，表内内容方向行标题是否不带序号，且没有截图。
- “四、选题建议”是否以紧凑表格呈现15-30条选题，主题组标题是否带1、2、3……序号，仍然只给标题和方向层级的建议。
- “五、对标账号参考”是否与用户确认的最终名单完全一致，包括用户新增或替换的账号。人数和类型以该名单为准。每项是否按顺序编号，主页截图对应正确，近期表现含时间范围、样本与可见指标，内容分析、推荐理由、借鉴点及不宜照搬之处有资料支持。材料缺口是否由用户明确接受且已说明边界。仍待补的账号不能以占位文字进入成稿。
- 对常规品牌账号及素人图文铺量，是否优先选同品类、同客群的同平台品牌自营账号。中途3–5个候选（不足按实列出）及最终入选的官方账号、区域号或门店号是否均有具体归属依据。归属不明的是否已补证或换选。达人、素人、探店和第三方带货合作帖是否仅作为内容示例，未计入第五模块的自营账号。个人IP常规方案按原候选评审规则检查。
- 第六模块内部小标题是否按实际出现顺序从1编号。
- 有没有把原参考案例的身份、历史数据或具体业务建议误用为当前客户事实。
- 是否只参考用户定位示例的表达结构，没有将成都、江景园林、1000㎡、9席等信息误作菇菇哒或其他账号事实。

**素人图文铺量PDF内容检查**

- 首页方案名是否为“素人图文种草方案”。五个模块是否依次为“一、铺量目标与品牌号配合”“二、素人图文方向与选题”“三、种草帖示例”“四、从示例延展的选题”“五、对标账号参考”。
- 品牌号辅助内容是否简短。是否有至少15个可区分的内容方向，每个都有具体图文拟题、人群或场景与切入视角。相同方向的多个拟题按一个方向计数。
- 有目标篇数时，各方向分配是否与其一致。无目标篇数时，若使用15方向各2题、约30条的估算，是否标明为建议量。
- 采用的用户原帖截图是否实际进入PDF、清晰可读，并与相同编号的案例及可借鉴做法相邻。是否结合目标平台语境改写，另列本批案例衍生的3–5个原创题，每题都可追溯到对应示例。
- 方向和拟题是否经过用户保留、替换或补充。初审后新增的衍生题或实质修改是否已确认。是否也完成独立的对标账号评审。还有示例待收集或方案待确认时不出最终稿。
- 所有拟题和场景是否基于真实信息，需实拍或实测的素材是否标明。交付物供后续创作使用，不能把设想写成已发生的消费体验或评价。

任何一项不合格，都要修改模板并重新渲染全部页面。
