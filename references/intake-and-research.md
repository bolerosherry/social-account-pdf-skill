# 资料与研究规则

## 启动提示与资料收集

每次用户明确唤起一个新案例，先识别两个独立选择：做标准账号方案还是素人图文铺量，以及交付PDF还是飞书文字。已经指定其中一项就只问另一项，两项都已指定就直接收集缺少的资料。不要根据交付形式推测运营模式，也不要在未选择格式时默认生成PDF。

模式未指定时可问“这次是做标准账号方案，还是以素人图文铺量为主？”选项为“标准账号方案”和“素人图文铺量”。

格式未指定时，使用以下问题和选项：

> 这次方案你希望用哪种形式交付？
>
> - PDF 文件
> - 可复制到飞书的文字

`request_user_input_async` 可用时，同次询问尚未确定的选择，每个问题只对应一项。不可用时以普通文字询问。所缺资料清单用普通说明给出，可以与这两个选择在同次回复中提供。不要在选择工具中索要截图或文件。

- 只有口令时，可一次询问模式和形式，并提示以下资料清单。
- 已附部分资料时，简短确认已收到的内容，仅询问未定选择和仍缺且有用的资料。
- 模式、形式与启动资料齐全时直接开始分析和寻找候选。两种模式均按下述流程确认对标名单。
- 同一案例补资料或改稿时，沿用已选模式和形式，用户明确调整其中一项时只更新该项。新案例采用该案例的明确选择。

选择尚未确认时可以读取已有链接、整理证据。以下为标准账号方案的资料提示示例，实际只保留缺项。素人图文铺量先收集业务与目标平台、目标人群或场景、已定篇数（如有）及现有素材。品牌号的资料仅用于辅助说明，铺量所需的素人原帖按下述评审流程征集。

> 已启动「动量领航方案」。请提供以下资料，已有的直接发我即可：
>
> 1. **账号主页链接**：小红书或抖音的主页分享链接。
> 2. **账号截图**：完整主页（昵称、简介、粉丝量、获赞与收藏）和近期内容列表；长页面可分几张截图。
> 3. **代表内容**：2-4篇笔记或视频的截图，尽量能看清封面、标题、正文及互动数据；视频可附原视频或文字说明。
> 4. **业务背景**：公司或品牌名称、主要产品/服务；本地业务注明城市或门店，个人IP说明真实身份、经历或专业领域。
> 5. **本次目标**：例如到店、咨询、销售、涨粉或品牌曝光。
>
> 有产品/服务资料、菜单或价目表、喜欢的对标账号、后台数据，也可以一并提供，这些是选填。可先发链接和业务背景、目标，截图稍后补充；不方便发链接时，也可先用清晰截图开始。

平台、主体、名称等已能从本次资料确认的信息直接使用，不再单独追问。允许分批提供资料；可以先读取现有链接并整理证据。不要为了收齐所有可选项阻塞工作，但不能在没有可辨识账号或足够样本时假称完成账号分析。

## 基础信息与可选补充

- 客户公司或品牌名称（用于报告名称）；个人IP使用用户确认的主体名称。
- 平台：小红书或抖音，优先从链接或截图识别。
- 账号主页链接；无法提供或无法读取时，接受可辨识账号的主页及内容截图作为替代证据。
- 账号主体：个人 IP（`person`）或饭店、企业、品牌等非个人主体（`brand`），优先从资料识别。
- 主要业务及本次运营目标；涉及地域的业务补充服务城市、门店或覆盖范围。

主页与代表内容截图用于诊断；仅已指定的一张账号首页截图在阶段表展示，代表内容截图只作分析依据，选择可复制到飞书的文字时仍可作为分析证据。后台数据、产品或服务详情、菜单或价目表、用户已有的对标账号和执行限制为可选补充；不要求用户承担对标研究。个人 IP 的身份经历、人设资源，以及企业的主要业务和承接方式，优先使用用户已提供的信息；缺失且影响定位时再追问。缺失的粉丝量、获赞或简介等不能编造，也不要求用户手动重填截图上已清楚显示的数据。

个人 IP 资料用于回答“我是谁、我帮谁、我分享什么、我怎么表达”，不能以出镜或拍摄安排代替人设。非个人主体核实品类价值、地域或场景、目标人群和差异标签，用于形成账号定位。用户给出的成都、江景园林、1000㎡、9席等表达示例只作结构参考，不作为菇菇哒或其他账号的事实。

账号昵称按来源原文记录，主页展示使用用户提供的原图。将可见粉丝量、获赞与收藏和简介作为当前阶段的直接证据；只有内容列表或不完整主页时，明确记录“主页局部截图”，不能据此补全账号资料。用户给出的示例表格只用于参考结构，不能当成当前账号的新事实。

## 链接无法读取

不要推测页面内容。先检查用户是否已给过主页与代表内容截图，只补充索取仍缺少的证据。截图尽量包含昵称、简介、粉丝量、获赞/收藏量、近期内容及可见日期；不要重复索取已清楚显示的数据。不可获得的公开数据记为“暂未获取”。

## 对标账号

**在当前聊天发出候选清单。** 初选3–5个同平台、真实且可定位的账号。素人图文铺量和常规品牌账号方案只从品牌自营账号中选，优先考虑同品类、同客群。可选品牌官方账号，也可选归属已经核实的官方区域号或门店号。个人IP的常规账号方案仍按项目的同赛道、相近阶段或内容形式筛选。如果只核实了1个，就列这1个并请用户补充。如果一个也未找到，就报0个，请用户提供账号名称、链接或截图。

每个候选单列一行。填写账号的精确显示名称和至少一项可定位依据（主页链接、平台ID，或足以区分同名账号的具体线索），简述初选依据，再分别写明已核实什么、还需确认什么。品牌及铺量项目每行另写**所属品牌与自营依据**，如主页认证主体与品牌关系可核对、品牌官网链接指向该主页、品牌官方总号公开列出该区域或门店账号。地址、店名、昵称带“官方”或发布过品牌合作内容，均不足以单独确认自营。保留来源链接、可见标识、核验日期及截图来源的内部记录。

品牌及铺量项目收到达人、素人、探店或第三方带货合作号时，将用户提供的具体帖子归为内容示例。铺量模式可在“三、种草帖示例”分析原帖和可借鉴做法，按实际情况注明合作属性。账号归属不明时，向用户索取可核对的依据，或请其换选。上述账号和未核实账号不计入自营候选或最终名单，用户新增、替换的候选也执行同一规则。历史案例、品牌名和被分析账号自身内容不能冒充已核实的对标账号。

**等用户选定，再分析入选账号。** 请用户明确哪些保留、排除、替换或新增，同时只提示入选者仍缺的材料。用户可在同一条消息里选名单、发材料。如果已明确“用这几个”或点名新增某账号，就按该决定处理，不再询问一次。未答复时可以继续原账号诊断和选题准备，先保留候选状态。用户替换或新增的账号按同一标准核实、补资料和分析，最终人数及类型随已确认名单确定。

| 每个入选账号要了解的内容 | 可直接使用的材料 |
| --- | --- |
| 账号主页 | 可辨识昵称、平台ID等信息的原始主页截图，链接或标识用于核对同名账号。 |
| 近期表现 | 明确时间范围、样本（哪些内容、多少条）、可见指标及对应值。可用有日期的截图、链接、表格或文字记录。只描述可见样本的表现。 |
| 内容分析 | 代表笔记或视频、标题与封面、正文截图，或用户对代表内容的观察，用于判断具体选题、结构与表达方式。 |
| 推荐理由 | 用户想参考这个账号的原因、它和目标账号的关联。用户只发原材料也可以，由助手据此提炼推荐理由、可借鉴做法和适用边界。 |

已有链接、截图和说明直接复用，能从中确认的信息由助手整理。仍有缺口时在当前聊天一次列出账号和具体缺项，等待补充。用户明确接受某一缺口时，记录可用证据范围，继续分析能够支持的部分。接受缺口不等于核实账号身份或取得缺失数据。

**交付条件。** 用户明确最终名单，所有入选账号均已核实，资料已补齐或具体缺口已获明确接受，且助手已完成逐个分析，对标评审才算完成。未处理的缺项留在研究记录中。标准模式据此完成交付。选择素人图文铺量的项目还要完成下面的方向评审与帖子示例分析。

## 素人图文铺量的方向评审与示例

1. 将品牌号的定位、可核实的产品信息与承接方式压缩为少量辅助内容。围绕真实人群、需求和使用场景，先在当前聊天列出至少15个实质不同的内容方向。每行给方向编号、目标人群或场景、创作视角及具体图文拟题。只换近义词或地名的标题算同一个方向。已有目标篇数时按方向分配，总数与目标一致。未给篇数时可建议15个方向各拟2题，约30条，标明是建议量。
2. 请用户按编号选择保留、替换、补充，并主动请用户上传手头的小红书或抖音素人图文原帖截图。抖音项目也可引用小红书截图作为创作示例，图注标明来源平台，拟题按投放平台改写。已提交的截图直接使用，按“示例1、示例2……”标识，选定方向或提出修改的消息也可同时完成这一步。收到实质调整后，只把受影响的方向、拟题和新增项发回当前聊天确认。
3. 对每个采用的示例展示用户提供的原截图，写出图文顺序、提问方式、使用场景等具体可借鉴做法，再结合本项目可核实的信息，在目标账号所属平台的语境下改写。基于本批示例另提3–5个原创选题，逐项标明对应示例和具体切入点，与首批方向分开列。
4. 如果示例在初审前已提供，可将方向、拟题、原图借鉴点和追加原创题一次交用户选择。如果初审后才收到截图，把新增的3–5题发回当前聊天，请用户只确认这些新增题。用户已确认方向、拟题及追加原创题，实际示例分析和对标账号的独立评审都完成后，交付所选格式。两个评审可并行。还有实质修改待确认或示例待补时，留在当前聊天推进。已确认的事项无需重问。

所有题目都作为制作建议。只写品牌资料、原帖或其他依据能支持的事实。尚待实拍、实测或真实到店的内容标作待采集素材，避免虚构消费者身份、体验、评价或结果。交付到方案为止。

## 热点

研究生成当日可验证的平台热点、行业热点和时间节点。只有当热点与账号定位、目标用户和执行资源明确匹配时才采用；不匹配时允许不给热点型选题。

热点需归入已有内容方向，附内部核验日期和依据；不要把原案例中的节日、热梗或历史选题直接称为当前热点。
